# Pasta de Vídeos - Despachante Falcão

## Estrutura de Organização

Esta pasta contém os vídeos educativos e informativos do Despachante Falcão, organizados por categorias:

### 📁 Estrutura de Pastas

- **licenciamento/** - Vídeos sobre licenciamento veicular
- **transferencia/** - Vídeos sobre transferência de veículos  
- **ipva/** - Vídeos sobre IPVA e consultas
- **vistoria/** - Vídeos sobre vistoria e inspeção veicular
- **cnh/** - Vídeos sobre serviços de CNH (renovação, primeira habilitação, etc.)
- **orientacoes/** - Vídeos gerais e orientações

### 📝 Nomenclatura de Arquivos

Use nomes de arquivos simples, sem espaços e sem caracteres especiais:

- ✅ BOM: `licenciamentor.mp4`, `orientacao.mp4`
- ❌ RUIM: `Licenciamento Veículo (2024).mp4`, `CNH - Renovação@#.mp4`

### 🎬 Formatos Recomendados

- **MP4** com codec H.264 (mais compatível)
- **WebM** (alternativa moderna)
- Tamanho máximo recomendado: 50MB por vídeo
- Resolução recomendada: 720p ou 1080p

### 🔧 Como Adicionar Vídeos

**IMPORTANTE:** Os vídeos são configurados manualmente no código HTML. Não carregam automaticamente.

1. Coloque o arquivo de vídeo na pasta correspondente
2. Use nomes descritivos e simples
3. Adicione o vídeo no código HTML (`index.html`) com o caminho correto
4. Atualize os arquivos `GitHub/index.html` e `GitHub/Index2/index.html` também

### ⚠️ Importante

- Não inclua informações pessoais de clientes nos vídeos
- Verifique se há consentimento para gravações com pessoas
- Mantenha os vídeos atualizados
- Remova vídeos desatualizados quando necessário
- Após adicionar um novo vídeo, atualize o código HTML nas 3 cópias do site
