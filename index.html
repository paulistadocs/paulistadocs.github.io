Enviar Documentos

Envie seus documentos de forma segura

📋 Como funciona:

  1. 1. Clique para adicionar arquivos (pode repetir várias vezes)
  2. 2. Navegue em diferentes pastas e adicione mais arquivos
  3. 3. Visualize todos os arquivos selecionados
  4. 4. Clique em "Enviar Agora" quando estiver pronto
  5. 5. Confirme o envio via WhatsApp/Email

⚠️ Importante: Os dados ficam salvos apenas neste dispositivo. Se fez cadastro em outro dispositivo, precisa se cadastrar novamente aqui.

📎 Como funciona:
1. Selecione os arquivos que deseja enviar
2. Clique "Enviar Agora" para notificar a DESPACHANTE FALCÃO
3. Um email será enviado com a lista dos seus arquivos
4. A DESPACHANTE FALCÃO entrará em contato para solicitar os documentos
5. Você poderá enviar por WhatsApp, email ou entregar pessoalmente
